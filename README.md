# yzc-666.github.io

Personal homepage of **Zichao Yu**, PhD student at the University of Hong Kong. The site covers mechanistic interpretability and large language model post-training.

## Where things live

- Bio, research interests, and links are in `site/index.html`.
- Styles are in `site/assets/home.css`.
- The profile photo is in `site/assets/img/prof_pic.jpg`.

Open `site/index.html` in a browser for a local preview. GitHub Pages publishes the contents of `site/` through `.github/workflows/deploy.yml` on pushes to `main`. The workflow can also be run manually from the Actions tab.
